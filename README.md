# Employee Management System (Java CLI)

A simple command-line app to manage employee records.

## Features
- Add Employee
- Update Employee
- Delete Employee
- Search Employee (by ID or Name)
- List All Employees
- Highest Salary Employee
- Average Salary
- Filter Employees by Department

## Requirements
- Java JDK 8 or higher

## How to Run

1. Open a terminal in the project folder.
2. Compile the code:
   ```
   javac EmployeeManagementSystemOptimized.java
   ```
3. Run the program:
   ```
   java EmployeeManagementSystemOptimized
   ```

## How to Use
- A menu appears with options 1–9.
- Type a number and press Enter to choose an option.
- Follow the on-screen prompts (Name, Department, Salary, etc).
- Choose **9** to exit.

## Data Storage
Employee records are saved automatically to `employees.txt` in the same folder, so your data stays even after you close the program.
